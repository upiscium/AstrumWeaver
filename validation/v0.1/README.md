# v0.1 Hardware Validation Evidence

This directory is reserved for **redacted hardware-e2e acceptance evidence**.

Do not commit raw site logs or configuration.

Allowed evidence contains only public-safe fields produced by:

```text
astrumweaver-hardware-accept
```

Private hostnames, addresses, VM/LXC identifiers, actual GPU UUIDs, credentials, private URLs, GPU models, and site topology must remain outside the repository.

See [docs/hardware-e2e.md](../../docs/hardware-e2e.md).
